# compositional.mle v1.0.0 — Clean Slate Design

**Date:** 2026-03-16
**Status:** Approved (post-review revision)
**Scope:** Breaking redesign for algebraic.mle 2.0 compatibility, result object cleanup, likelihood.model integration, API surface refinement, and bug fixes.

---

## Goals

1. Full compatibility with `algebraic.mle >= 2.0.0` (class rename `mle_numerical` -> `mle_fit_numerical`)
2. Clean result object structure with nested `$solver_info` metadata
3. Bridge to `likelihood.model` via `mle_problem.likelihood_model()` constructor
4. API surface cleanup (remove redundancies, fix naming)
5. Fix all code review bugs (10 issues, 3 critical + 7 important)

## Non-Goals

- Bidirectional bridge (`fit.likelihood_model()` method) — deferred to later release
- Trace system overhaul (automatic tracing) — deferred
- Solver protocol formalization — deferred

## Section 1: Result Object Redesign

### Class Vector

All solvers return objects with class:
```
c("solver_result", "mle_fit_numerical", "mle_fit")
```

Per-solver subclasses (`"mle_gradient_ascent"`, `"mle_bfgs"`, `"mle_grid_search"`,
`"mle_random_search"`, etc.) are removed — solver identity lives in `$solver_info$name`.

### Structure

Statistical inference fields live at top level (inherited from `mle_fit`):
- `$theta.hat` — point estimate
- `$sigma` — variance-covariance matrix
- `$loglike` — log-likelihood at MLE
- `$converged` — convergence flag (from `mle_fit_numerical`, used by S3 dispatch)

All solver/optimization metadata lives in `$solver_info`:
```r
result$solver_info <- list(
  name        = "gradient_ascent",   # character: solver name
  iterations  = 47L,                 # integer: total iterations
  converged   = TRUE,                # logical: convergence (mirrors top-level for introspection)
  trace_data  = <mle_trace_data>,    # mle_trace_data or NULL

  composition = NULL,                # NULL for single solvers, or list:
  # composition = list(
  #   strategy       = "sequential",   # "sequential"|"race"|"restarts"|"chain"|"conditional"
  #   chain          = list(...),      # sub-results (sequential/chain)
  #   alternatives   = list(...),      # sub-results (race)
  #   winner_index   = 2L,             # integer (race)
  #   n_restarts     = 20L,            # integer (restarts)
  #   restart_loglikes = numeric(...), # numeric (restarts)
  #   stopped_early  = FALSE           # logical (chain with early_stop)
  # ),

  diagnostics = NULL                 # NULL or list of solver-specific fields:
  # diagnostics = list(
  #   final_temp      = 0.001,         # sim_anneal
  #   acceptance_rate = 0.23,          # sim_anneal
  #   cycles          = 12L,           # coordinate_ascent
  #   grid_points     = 100L,          # grid_search
  #   grid_evaluated  = 87L,           # grid_search
  #   n_samples       = 100L,          # random_search
  #   n_evaluated     = 95L            # random_search
  # )
)
```

**Note on `$converged` duplication:** The top-level `$converged` is set by
`mle_numerical()` and is what `is_converged.default()` reads via S3 dispatch.
`$solver_info$converged` mirrors it for composition introspection (e.g., checking
convergence of sub-results in a chain without relying on S3 dispatch).

### Builder Function

`.build_result()` is the single constructor (stays in `verbose.R`, internal).
**All solvers must use this function** — including `grid_search()` and
`random_search()`, which currently bypass it and call `mle_numerical()` directly.

```r
.build_result <- function(theta, ll, converged, hessian, solver_name,
                          iterations, recorder, n_obs = NULL,
                          diagnostics = list()) {
  sol <- list(par = theta, value = ll,
              convergence = if (converged) 0L else 1L,
              hessian = hessian)

  mle <- algebraic.mle::mle_numerical(sol = sol, superclasses = "solver_result")
  if (!is.null(n_obs)) mle$nobs <- n_obs

  mle$solver_info <- list(
    name = solver_name,
    iterations = as.integer(iterations),
    converged = converged,
    trace_data = finalize_trace(recorder),
    composition = NULL,
    diagnostics = if (length(diagnostics) > 0) diagnostics else NULL
  )

  mle
}
```

**`.optim_to_mle()` update:** The existing `.optim_to_mle()` in `solver_optim.R`
must be refactored to delegate to `.build_result()`:

```r
.optim_to_mle <- function(optim_result, solver_name, recorder = NULL) {
  .build_result(
    theta = optim_result$par,
    ll = -optim_result$value,
    converged = optim_result$convergence == 0,
    hessian = -optim_result$hessian,
    solver_name = solver_name,
    iterations = optim_result$counts["function"],
    recorder = recorder
  )
}
```

### S3 Methods on `solver_result`

```r
print.solver_result(x, ...)
plot.solver_result(x, type, ...)
optimization_path.solver_result(x, ...)
is_converged.solver_result(x, ...)
num_iterations.solver_result(x, ...)
```

All `algebraic.mle` generics (`params()`, `vcov()`, `confint()`, `logLik()`, `AIC()`,
`se()`) work via S3 fallthrough to `mle_fit_numerical` / `mle_fit`.

**Note:** `plot.mle_trace_data` currently creates a fake wrapper with
`class(wrapper) <- "mle_numerical"` (plot.R:199). This must change to
`class(wrapper) <- "solver_result"`.

## Section 2: likelihood.model Bridge

### S3 Generic Dispatch

`mle_problem()` becomes an S3 generic. The first formal parameter stays `loglike`
(not renamed to `x`) to preserve backward compatibility with all existing callers
that use `loglike = function(theta) ...` as a named argument:

```r
mle_problem <- function(loglike, ...) UseMethod("mle_problem")
```

S3 dispatches on `class(loglike)`. When `loglike` is a function →
`mle_problem.default()`. When `loglike` is a `likelihood_model` →
`mle_problem.likelihood_model()`.

The current constructor signature becomes `mle_problem.default()` unchanged —
the first positional arg is still `loglike`:

```r
mle_problem.default <- function(loglike, score = NULL, fisher = NULL,
                                 constraint = NULL, theta_names = NULL,
                                 n_obs = NULL, cache_derivatives = FALSE, ...) {
  # existing implementation, unchanged
}
```

### mle_problem.likelihood_model

```r
mle_problem.likelihood_model <- function(loglike, data, constraint = NULL,
                                          theta_names = NULL,
                                          cache_derivatives = FALSE, ...) {
  model <- loglike  # first arg is the likelihood_model object
  ll_fn <- loglik(model)      # likelihood.model convention: returns function(df, par)
  sc_fn <- score(model)       # returns function(df, par)
  hl_fn <- hess_loglik(model) # returns function(df, par) -> Hessian

  # Guard against non-tabular data
  n_obs <- if (is.data.frame(data) || is.matrix(data)) nrow(data) else length(data)

  # Note on sign convention: hess_loglik returns the raw Hessian of the
  # log-likelihood (negative semi-definite at MLE). mle_problem$fisher expects
  # the Fisher information matrix (positive definite), which is -Hessian.
  mle_problem.default(
    loglike = function(theta) ll_fn(data, theta),
    score = function(theta) sc_fn(data, theta),
    fisher = function(theta) -hl_fn(data, theta),
    constraint = constraint,
    theta_names = theta_names,
    n_obs = n_obs,
    cache_derivatives = cache_derivatives
  )
}
```

### Usage

```r
# From likelihood.model (new bridge):
problem <- mle_problem(model, data)

# Direct specification (unchanged, backward compatible):
problem <- mle_problem(loglike = function(theta) ..., score = ..., constraint = ...)
```

### Dependency

- `likelihood.model` in `Suggests` (not `Imports`)
- Method is always registered; S3 dispatch only fires when a `likelihood_model` is passed
- Tests use `skip_if_not_installed("likelihood.model")`

### Result Type

Solver returns `solver_result` / `mle_fit_numerical` regardless of problem source.
Users who need `fisher_mle` for Fisherian inference construct it from the result
(documented pattern in vignette).

### `fisher_scoring` Alias

`fisher_scoring <- newton_raphson` means results have `solver_info$name = "newton_raphson"`.
Update the alias so that `fisher_scoring()` wraps `newton_raphson()` and overrides the
solver name:

```r
fisher_scoring <- function(...) {
  solver <- newton_raphson(...)
  function(problem, theta0, trace = mle_trace()) {
    result <- solver(problem, theta0, trace)
    result$solver_info$name <- "fisher_scoring"
    result
  }
}
```

## Section 4: Bug Fixes

### Critical (algebraic.mle 2.0 compatibility)

These are pre-existing breakages — the test suite already fails with algebraic.mle
2.0.0 installed due to class renames.

1. **S3 method registration** — all methods re-registered for `solver_result`
2. **`is_mle_numerical()`** — replaced by `is_solver_result()` checking `inherits(x, "solver_result")`
3. **Test generic references** — `loglik_val()` -> `as.numeric(logLik())`, `aic()` -> `AIC()`

### Important

4. **`print.mle_trace_data` null-check ordering** (`trace.R:185`) — move element access inside null+length check:
```r
if (!is.null(x$values) && length(x$values) > 0) {
  cat("  Log-likelihood: ", round(x$values[1], 4),
      " -> ", round(tail(x$values, 1), 4), "\n", sep = "")
}
```

5. **`print.mle_problem` constraint detection** (`problem.R:113`) — add `is_default` sentinel flag to `mle_constraint()`:
```r
mle_constraint <- function(support = function(theta) TRUE,
                           project = function(theta) theta) {
  structure(list(support = support, project = project,
                 is_default = missing(support) && missing(project)),
            class = "mle_constraint")
}
```

6. **NEWS.md / vignette stale references** — `loglik_val()` -> `logLik()`, `aic()` -> `AIC()`, `dfr.dist` -> `flexhaz` (with corrected description: "distributions via arbitrary hazard functions")

7. **`sim_anneal` convergence lie** (`solver_annealing.R:139`) — report `converged = (temp < min_temp)` instead of always TRUE

8. **Coordinate ascent hardcoded step** (`solver_coordinate.R:125`) — add `learning_rate` parameter to `coordinate_ascent()`, use `learning_rate * grad_j` instead of `0.1 * sign(grad_j)`

9. **`grid_search` explosion** (`solver_grid.R:54`) — guard before `expand.grid()`:
```r
grid_size <- prod(n)
if (grid_size > 1e6) {
  stop("Grid would have ", format(grid_size, big.mark = ","),
       " points. Reduce n or use fewer dimensions.")
}
```

10. **`race()` silent parallel fallback** (`compose.R:136`) — emit warning when `parallel = TRUE` but `future` not installed:
```r
if (parallel && !requireNamespace("future", quietly = TRUE)) {
  warning("parallel = TRUE but 'future' package not installed. ",
          "Falling back to sequential execution.",
          call. = FALSE)
}
```
